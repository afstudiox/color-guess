# Projeto Color Guess

## Sobre

Aplicação de um jogo que tem por objetivo adivinhar a cor do código RGB apresentado, clicando nos círculos coloridos. A pontuação é atualizada conforme os acertos.

[Teste a aplicação aqui](https://afstudiox.github.io/color-guess/)

_Observações_
  - As cores são criadas dinamicamente.
  - As 3 melhores pontuações ficam salvas no navegador (localStorage) e são exibidas em um ranking.

_Requisitos_
  - Utilizar somente HTML5, CSS e JavaScript ES6.


## Contexto

Este projeto foi desenvolvido durante minha formação na Trybe, com foco em manipulação do DOM, eventos e estilização básica com HTML, CSS e JavaScript.

Em uma revisão posterior, o projeto foi mantido sem frameworks ou ferramentas de build para preservar o escopo original do exercício. As melhorias foram concentradas em legibilidade, semântica, acessibilidade simples e documentação.


## Habilidades

- Manipular o DOM.
- Lógica de programação com JavaScript.
- Estilização com CSS.


## Desafios
- [x] - Exibir um título com o nome do jogo
- [x] - Exibir dinamicamente o código RGB a ser adivinhado
- [x] - Gerar cores RGB aleatórias para as opções
- [x] - Atribuir as cores geradas aos círculos da paleta
- [x] - Ao clicar em um círculo, indicar se a cor escolhida está correta ou não
- [x] - Incrementar o placar em 3 pontos a cada acerto

## Como testar localmente

1. Clone o repositório:

```bash
git clone git@github.com:afstudiox/color-guess.git
```

2. Acesse a pasta do projeto:

```bash
cd color-guess
```

3. Abra o arquivo `index.html` no navegador.
